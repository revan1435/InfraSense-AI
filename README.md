# InfraSense AI

**Team: NOVASENSE**

InfraSense AI is an AI-powered smart infrastructure monitoring and disaster-risk awareness platform.

## Key Features
- Infrastructure monitoring dashboard
- Sample IoT sensor readings
- Risk indicators and alerts
- Citizen and government portal interface concepts
- Disaster preparedness and preventive maintenance support

## Technology
HTML, CSS, JavaScript, and a proposed future IoT/AI backend.

## Prototype Status
This is a demonstration prototype. Sensor readings are simulated; it is not connected to live hardware or a production AI model.

## Future Scope
Integrate ESP32 sensors, a secure backend, a database, GIS mapping, and validated risk prediction models.
